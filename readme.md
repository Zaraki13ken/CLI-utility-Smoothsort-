# Плавная сортировка (Smoothsort)

Реализация консольной утилиты для сортировки числовых и текстовых данных алгоритмом **плавной сортировки (smoothsort)**, а также модуль для её пошаговой графической визуализации.

Проект выполнен в рамках практической работы №3 «Алгоритмы сортировки».

## Возможности
- Работа с числовыми данными.
- Работа с текстовыми данными.
- Сортировка по неубыванию/невозрастанию.
- Чтение и запись данных в файл.

## Стек
- Python 3.13.7

## Установка
```bash
git clone https://github.com/Zaraki13ken/CLI-utility-Smoothsort-
cd CLI-utility-Smoothsort-

python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или venv\Scripts\activate для Windows

pip install -r requirements.txt
```

## Использование
- **Сортировка чисел по возрастанию (вывод в консоль)**
    ```bash
    python main.py --data "[2, -3, 5, 0, 5]" --numeric
    ```
- **Сортировка строк по убыванию**
    ```bash
    python main.py --data "banana apple cherry" --reverse
    ```
- **Чтение из файла, запись результата в файл**
    ```bash
    python main.py --input nums.txt --numeric --output sorted.txt
    ```
- **Генерация случайного списка и его сортировка**
    ```bash
    python main.py --visualize --size 15
    ```
## Аргументы командной строки
- **--input PATH FILE** - Входной файл (по одному значению на строку).
- **--data STR** - Данные в командной строке "[2, -3, 5]".
- **--output PATH FILE** - Выходной файл для записи результата.
- **--reverse** - Сортировка по невозрастанию
- **--numeric** - Интерпретировать данные как целые числа.
- **--visualize** - Запустить графическую визуализацию.
- **--interval NUM** - Задержка между кадрами анимации в мс (больше = медленнее, по умолчанию 500).
- **--size NUM** - Генерирует случайный список с данным размером
